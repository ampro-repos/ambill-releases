Security & deployment

Your data stays on your infrastructure

In a standard installation ampro runs as a desktop application against a SQL Server that you control.

On your own servers

Databases live in SQL Server on your PC or server. Uninstalling the application does not delete them.

Role-based access

Assign permissions by role so each person sees and does only what their job requires.

Protected connection settings

Database connection details are stored encrypted with Windows data protection on the machine that uses them.

Offline licence verification

Licences are verified locally against a signed licence file, so day-to-day use does not depend on an internet connection.

Support

Frequently asked questions

Which installer should I choose?

For daily work choose the financial-year installer for the year you are working in. Each year is its own application with its own database, and several years can sit side by side. The generic installer is a single application where you choose the year or years during setup.

Windows says the file isn’t commonly downloaded. Is it safe?

The installers are not code-signed yet, and Windows warns about new, unsigned files. Choose Keep in the browser, then Run anyway. We are working on signing the installers so this warning goes away.

Do I need an internet connection?

Only to download the installer and, on a PC without SQL Server, to fetch SQL Server Express during setup. If a PC will be offline, ask for an offline installer.

How do updates work?

The application checks for new versions and offers to update. Each financial-year application updates only with its own year, so one year’s update never affects another.

Where is my data stored? What happens if I uninstall?

Your data lives in SQL Server on your own machine or server. Uninstalling the application does not delete your databases.

How do I activate my licence?

ambill asks for your licence when it first starts. Enter the details you were given, or contact your ampro representative.

Need help choosing or installing?

Your ampro representative can help you pick the right edition, plan your rollout and move existing data across.
