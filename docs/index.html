Connect your GitHub account
Stored only in this browser (localStorage) — never sent anywhere except api.github.com.
  1. GitHub → your profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Resource owner: ampro-repos. Repository access: Only select repositories → ambill-releases AND ambill-error-reports (select both — the same token now drives both the License Requests and Crash Reports tabs on this page)
  3. Permissions → Repository permissions: Issues → Read and write · Actions → Read and write · Deployments → Read and write · Contents → Read and write
    (on ambill-error-reports only Issues → Read and write is actually needed)
  4. "Deployments" is a separate permission from "Actions" — per GitHub's own docs, it's specifically what "Approve & Sign Now" needs to review a pending deployment. Easy to miss; without it you'll get a 403.
  5. Approving also requires the token's own account to actually be the required reviewer on the license-signing environment (currently mcankalx) — a token from any other account will still 403 even with every permission above granted.
  6. Generate, copy the token, paste it above.
